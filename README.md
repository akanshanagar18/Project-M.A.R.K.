# Project M.A.R.K.
### Mapped Automation Route Kinematics

**A C++ Based Ride-Pooling and Smart Commuting System**

## Overview

Project M.A.R.K. is a C++-based commute and ride-pooling management system designed to help users find suitable travel partners based on their source, destination, travel time, transport mode, and budget.

The project aims to make everyday commuting more convenient and affordable by connecting individuals travelling along similar or overlapping routes.

It combines commuter management, intelligent ride matching, and route management to provide a structured approach to shared transportation.

## Key Features

- **Commuter Profile Management:** Register, update, delete, and search commuter profiles.
- **Ride Request Management:** Create and manage ride requests.
- **Intelligent Ride Matching:** Identify compatible commuters based on routes, travel time, transport mode, and budget.
- **Priority-Based Matching:** Rank potential ride partners based on compatibility scores.
- **Route Management:** Represent transportation networks and identify suitable routes.
- **Ride History:** Maintain records of completed rides.
- **Search and Statistics:** Access commuter information and useful travel statistics.
- **Data Storage:** Store and retrieve user and ride information using JSON and CSV files.

## Technology Stack

- **Language:** C++
- **Programming:** Object-Oriented Programming
- **Data Structures:** Linked Lists, Queues, Priority Queues, Stacks, Graphs, Hash Maps, Vectors
- **Algorithms:** BFS, Dijkstra's Algorithm, Sorting, Searching
- **Storage:** JSON and CSV
- **Tools:** Visual Studio Code, Git, GitHub
