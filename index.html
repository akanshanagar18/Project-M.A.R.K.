Computer Science Data Structures Implementation

College C++ Project

1. Linked List

Used for user account records. Supports dynamic commuter insertion and traversal without fixed-size memory overhead.

2. Queue (FIFO)

Dispatches ride requests in strictly fair, first-come first-served sequential order.

3. Priority Queue (Max-Heap)

Ranks commuter compatibility based on geographical proximity, transit mode, and schedule overlap.

4. Stack (LIFO)

Provides instantaneous transactional rollback and undo functionality for completed trips.

5. Vector

Maintains the historical log of completed journeys and total system fare revenue.

6. Graph (Dijkstra & BFS)

Dijkstra uses min-heap priority queue for shortest physical distance. BFS uses FIFO queue for fewest intersections.
