🧠 Data Structure Architecture & Rationale

College Evaluation Reference
🔗

Linked List

Used in: User Management
Rationale: Facilitates O(1) dynamic user node insertion and flexible pointer-based deletion without contiguous array reallocation or size limits.

📥

Queue (FIFO)

Used in: Pending Ride Dispatch
Rationale: Enforces First-In-First-Out fairness in matching and dispatching incoming commuter requests in chronological arrival order.

⭐

Priority Queue (Heap)

Used in: Smart Ride Matching
Rationale: Evaluates multi-parameter compatibility (route overlap, time diff, budget, gender) and ranks candidates in O(log N) time using a Max-Heap.

↩️

Stack (LIFO)

Used in: Undo Operations
Rationale: Implements transactional rollback of ride requests and dispatch matches using Last-In-First-Out state restoration.

📦

Vector (Dynamic Array)

Used in: Completed Ride History
Rationale: Provides cache-friendly contiguous storage with fast O(1) amortized appending for finalized trips and financial audit records.

🕸️

Graph (Adjacency List)

Used in: Road Transport Network
Rationale: Represents road junctions as vertices and connecting road segments as weighted edges with physical distances in kilometres.

🛣️

Dijkstra's Algorithm

Used in: Shortest Road Distance
Rationale: Computes the mathematically minimal driving route across weighted road network edges using a Min-Heap priority queue.

🔄

Breadth-First Search (BFS)

Used in: Minimum Hops Route
Rationale: Explores unweighted graph levels using a FIFO Queue to find the path with fewest intersections / turnings.
